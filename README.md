# AITycoon

A satirical tycoon/base-building game about running an AI startup. Built with Godot 4 (GDScript).

## Run it
Open Godot, choose **Import**, select this folder's `project.godot`, then press **F5**.

## Controls (prototype)
- `1`-`4`: pick a room (Office, Server Hall, Lab, Cooling)
- Left click / drag: build
- Right click / drag: demolish (50% refund)
- WASD or arrow keys: pan, mouse wheel: zoom
